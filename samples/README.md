# Sample statements

Statements exported from web banking for the accounts in `data/ledger.db`.

| File | Account | Covers |
| --- | --- | --- |
| `gtb-2025-01.csv` | GTB Current (bank_a) | January 2025 |
| `gtb-2025-02.csv` | GTB Current (bank_a) | February 2025 |
| `gtb-2025-03-to-8th.csv` | GTB Current (bank_a) | 1 to 8 March 2025, exported early |
| `gtb-2025-03.csv` | GTB Current (bank_a) | all of March 2025 |
| `savings-2025-03.csv` | Savings (bank_b) | March 2025 |

The first and last lines of each file hold the bank's opening and closing balance.
